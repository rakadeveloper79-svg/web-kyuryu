Peraturan In-Game

  • Dilarang Cheat & Modifikasi Ilegal: Penggunaan client hack (X-Ray, Fly, KillAura, dll) berakibat pemblokiran permanen.
  • Dilarang Griefing: Merusak properti milik pemain lain atau mengambil aset di wilayah luar izin dilarang keras.
  • Dilarang Exploiting Bug: Penemuan celah bug wajib dilaporkan kepada pihak staff dan tidak dimanfaatkan.
  • Etika Obrolan: Hindari ujaran kebencian, perundungan, pornografi, dan isu SARA di obrolan publik.

Peraturan Grup Chat

  • Dilarang Spam: Hindari mengirimkan pesan berulang, stiker berlebihan, serta file berbahaya.
  • Dilarang Iklan Eksternal: Tidak diperkenankan mempromosikan server Minecraft lain di dalam platform grup resmi.
  • Relevansi Topik: Kirimkan pertanyaan atau laporan sesuai pada alur channel diskusi yang disediakan.

Frequently Asked Questions

Pertanyaan yang Sering Diajukan

Temukan jawaban cepat seputar server IP, dukungan platform, sistem klaim lahan, hingga rank.

Bagaimana cara bergabung ke KyuryuSMP?

Anda dapat bergabung menggunakan Minecraft Java Edition maupun Bedrock Edition (Android/iOS/Windows) dengan detail Server IP berikut:

  • IP Server: play.kyuryu.my.id
  • Port Bedrock: 19133
  • Port Java: Default (25565)
Apakah server ini mendukung pemain Bedrock/PE?
Ya, KyuryuSMP mengintegrasikan plugin Geyser & Floodgate, memungkinkan pemain Minecraft Bedrock (HP/Tablet/PC) untuk bermain bersama di dalam satu dunia dengan pemain Java Edition secara seamless.
Bagaimana cara mengamankan wilayah/bangunan saya?
Gunakan sistem Land Claim bawaan server. Setiap pemain baru (Rank Novice) mendapatkan kuota awal 5.000 Block & 2 wilayah klaim gratis untuk memproteksi bangunan dan chest milik mereka dari pemain lain.
Bagaimana prosedur pembelian Rank Privilese?
Seluruh pembelian Rank Privilese ditangani langsung oleh Owner resmi (SinChan) via WhatsApp demi keamanan transaksi. Silakan buka halaman lalu klik tombol WhatsApp pada paket yang Anda inginkan.
Siapa yang harus dihubungi jika mengalami bug/kendala?
Anda dapat menghubungi Tim Staff & Pengelola KyuryuSMP melalui halaman atau mengirim laporan pada grup obrolan resmi.
